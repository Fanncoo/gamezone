# GameZone — игровой портал для GitHub Pages

Статический сайт с подключением Supabase. До настройки Supabase сайт показывает демо-публикации. Для реальных аккаунтов, лайков, комментариев и админки подключи проект Supabase.

## Состав проекта

- `index.html` — главная, новости, обзоры, статьи, окна входа и регистрации.
- `admin.html` — админ-панель.
- `styles.css` — адаптивный тёмный дизайн.
- `app.js` — публикации, вход/регистрация, лайки и комментарии.
- `admin.js` — проверка роли администратора и управление публикациями.
- `config.js` — публичные URL и anon/publishable key проекта Supabase.
- `supabase/schema.sql` — таблицы и RLS-политики безопасности.

## A. Настрой Supabase

1. Открой https://supabase.com/ и создай проект.
2. В проекте выбери **SQL Editor → New query**.
3. Открой `supabase/schema.sql` из архива, скопируй весь текст, вставь в SQL Editor и нажми **Run**.
4. В настройках проекта найди **Project URL** и **anon/public key** или **publishable key**.
5. Открой `config.js` и заполни два поля:
   ```js
   window.GAMEZONE_CONFIG = {
     SUPABASE_URL: "https://ТВОЙ-ПРОЕКТ.supabase.co",
     SUPABASE_ANON_KEY: "ТВОЙ-ПУБЛИЧНЫЙ-ANON-ИЛИ-PUBLISHABLE-KEY"
   };
   ```
6. Сохрани `config.js`.

**Не вставляй** `service_role` или secret key в сайт или GitHub. Публичный ключ работает только вместе с правильными RLS-политиками.

## B. Назначь себя администратором

1. Опубликуй сайт по инструкции ниже.
2. На опубликованном сайте зарегистрируйся с email, которым будешь пользоваться как администратор.
3. Подтверди email, если Supabase требует подтверждения.
4. В Supabase открой **SQL Editor** и выполни запрос, заменив email на свой:
   ```sql
   update public.profiles p
   set role = 'admin'
   from auth.users u
   where p.id = u.id
     and u.email = 'YOUR_EMAIL@example.com';
   ```
5. Перезайди на сайт и открой `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/admin.html`.

Обычная регистрация даёт роль `user`, а не `admin`. Право администратора проверяется базой данных, а не только интерфейсом.

## C. Опубликуй сайт на GitHub Pages

1. Создай новый **Public** репозиторий на https://github.com/ (например, `gamezone`).
2. Загрузи в корень репозитория файлы `index.html`, `admin.html`, `styles.css`, `config.js`, `app.js`, `admin.js`, `README.md` и папку `supabase` целиком.
3. В репозитории открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**, branch `main`, folder `/ (root)`, нажми **Save**.
5. Подожди публикации. Адрес обычно будет `https://ТВОЙ-ЛОГИН.github.io/gamezone/`.
6. Админ-панель будет на `https://ТВОЙ-ЛОГИН.github.io/gamezone/admin.html`.

В Supabase открой **Authentication → URL Configuration** и добавь адрес сайта в разрешённые redirect URLs; проверь Site URL и настройки подтверждения email.

## Что уже есть и что можно добавить дальше

- Главная страница с демо-карточками новостей, обзоров и статей.
- Фильтры по типу публикации и поиск.
- Регистрация/вход через Supabase Auth.
- Лайки: один лайк на публикацию от каждого аккаунта; счётчик хранится в базе.
- Комментарии к публикациям, если база подключена.
- Админ-панель: создать, изменить, опубликовать, снять с публикации и удалить публикацию.
- Защита записей через Row Level Security (RLS).

Первая версия использует стилизованные эмодзи/цветные обложки вместо загрузки реальных изображений. Загрузка файлов в Storage, управление пользователями из панели и полноценная система модерации — следующие улучшения.
